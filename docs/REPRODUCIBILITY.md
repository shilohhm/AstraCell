# Reproducibility

Everything AstraCell claims is regenerated by a command in this document. No number is
quoted from memory; each is printed by the example named next to it. If a command's
output disagrees with a number in the docs, the docs are wrong — fix them to match the
run (§6).

---

## 0. The environment these numbers were produced on

| | |
|---|---|
| Python | 3.13.5 |
| numpy | 2.5.1 |
| matplotlib | 3.11.0 |
| pybamm | 26.6.2.0 (optional; examples 06–07, notebooks 03–04) |
| OS | Windows 11 (paths below give the POSIX variant too) |

The core (`identifiability`, `mismatch`, `calibration`) is **numpy-only**. PyBaMM is an
optional dependency; without it, the external-plant example/tests/notebooks skip cleanly
and the base install is unaffected. The Oxford real-cell path (`examples/08`, the `oxford`
tests) is a second optional extra — `.[oxford]` (scipy + h5py) plus the licensed dataset — and
skips just as cleanly without either. All Monte Carlo is seeded: a
`(scenario, n_trials, seed)` triple yields **bit-identical** arrays, asserted in
`tests/test_calibration.py`.

## 1. Fresh clone to a green tree

```bash
git clone <repository-url> astracell
cd astracell
git checkout v0.4          # or the latest release tag; core science unchanged since v0.4 (v0.5 packaged, v0.6 real-cell tooling, v0.7 breadth, v0.8 second-order depth)

python -m venv .venv
# Windows:
.venv/Scripts/python -m pip install -e ".[dev,notebook]"
# Linux / macOS:
.venv/bin/python -m pip install -e ".[dev,notebook]"

# optional: the external PyBaMM plant, for examples 06-07 and notebooks 03-04
.venv/Scripts/python -m pip install -e ".[pybamm]"

# optional: the Oxford real-cell loader (scipy + h5py), for example 08 and the oxford tests
.venv/Scripts/python -m pip install -e ".[oxford]"    # then: python scripts/fetch_oxford.py
```

Or, with [`uv`](https://docs.astral.sh/uv/): `uv venv && uv pip install -e ".[dev,notebook]"`.

Throughout this document `PY` means `.venv/Scripts/python` (Windows) or
`.venv/bin/python` (Linux/macOS). The `Makefile` targets take `PY=` to match:
`make check PY=.venv/bin/python`.

## 2. The gates (what CI runs)

| command | expected result |
|---|---|
| `$PY -m ruff check src tests examples scripts` | `All checks passed!` |
| `$PY -m mypy` | `Success: no issues found in 42 source files` |
| `$PY -m pytest` | `245 passed, 1 skipped` (~100 s, PyBaMM installed; the skip is the real-cell test, which needs the Oxford dataset — with it present, `246 passed`) |
| `$PY -m pytest -m "not pybamm and not oxford"` | `229 passed, 17 deselected` (the base-install guarantee — no optional deps, no dataset) |
| `$PY -m pytest -m pybamm` | `14 passed` (needs PyBaMM) |
| `make check` | runs ruff + mypy + pytest together |

The tests assert **theorems**, not observed numbers — a test that hard-codes "the SNR is
149" would break the moment the stand-in OCV curves are replaced with real ones, which is
the plan. Two tests are marked `regression` because they pin a *finding* on one
configuration, and say so.

## 4. Notebooks (and the output trap)

The four notebooks are generated from `scripts/build_notebook.py` but committed
**executed**, so they render with figures on GitHub. The builder strips outputs; you must
restore them before committing.

```bash
make notebook       # regenerate source from the builder (STRIPS outputs)
make notebook-run   # execute in place, restoring outputs
$PY -m pytest tests/test_notebooks.py   # guards BOTH: in sync with builder AND executed, error-free
```

Never edit the `.ipynb` by hand — edit `scripts/build_notebook.py`. See
[WHAT_DID_NOT_WORK.md](WHAT_DID_NOT_WORK.md) §4.

## 5. Release checklist

The ordered gate to run before tagging a release. Every step is a command above; this is
the sequence and the pass condition.

```
 0. git status --porcelain                     # empty: start clean
 1. make check                                 # ruff + mypy + pytest (245 passed, 1 skipped)
 2. examples 01-08 each exit 0                  # 01-07 regenerate 25 figures; 08 skips without the dataset
 3. $PY -m pytest -m "not pybamm and not oxford" # 229 passed, 17 deselected: the base-install guarantee
    (stronger form: move site-packages/pybamm aside, then `pytest` still exits 0 — the optional tests skip)
 4. make notebook && make notebook-run          # strip then restore notebook outputs
    $PY -m pytest tests/test_notebooks.py       # committed notebooks retain outputs, last run error-free
 5. figure regeneration confirmed               # reports/figures/ holds 25 PNGs after step 2 (26 with the Oxford dataset)
 6. stale-number grep (§6)                       # every pinned number still matches a live run
 7. git status --porcelain                      # empty except the changes you intend to ship
```

**Policy for step 6:** if a pinned number has drifted, the fix is to the **document**, to
match the reproducible output — never the reverse. Worse-but-truer is the goal.
