# v0.9 — Fit the dynamics

**Question:** does giving the observer freedom to *fit* the fast RC branch de-confound the real-cell
capacity verdict — or does it just trade model bias for confounding?

This is a **pre-registration**: the experiment, the hypotheses, the outputs, and the pass/fail gates
are written down *before* the run, so the result cannot be quietly reshaped to look good afterwards.

---

## Why this exists (the v0.8 handoff)

v0.8 measured that a *fixed* second RC branch is invisible to the `(R0, capacity)` fit — **0/208**
verdicts changed, largest `|1st − 2nd|` estimate `1.7e-14` — because the RC overpotentials cancel in
`∂V/∂R0` and `∂V/∂Q`. The conclusion, pinned in `REAL_CELL §Depth` / `LIMITATIONS §16e` /
`CLAIMS C20`: **model order enters the capacity verdict only by *fitting* the added dynamics.** v0.9
does exactly that — it stops holding the dynamics fixed and lets the estimator fit them.

## The governing law (do not break it)

The honesty mandate governs this work. The goal is **not** to make AstraCell look better — it is to
expose where the current confidence is over-optimistic. If the result gets *worse but truer*, that is
a success. Numbers are **measured, never asserted**: every public number is regenerated by a named
command, and if a run disagrees with a doc, the **doc** is wrong. A falsified pre-registration is
**retracted explicitly**, not buried. All gates stay green.

## The experiment

Turn the paired differential estimator from a **2-parameter** fit `(R0, capacity)` into a
**4-parameter** fit that also fits the fast RC branch `(R0, capacity, R1, C1)` — the dynamics v0.8
proved are invisible while fixed. Rerun the identical 8-cell Oxford loop and measure what moves.
(Optional stretch: 6-parameter, adding `R2, C2`.)

Build steps — *the code is the authority; verify every signature against it before editing:*

1. **Sensitivities.** `ParamKind` currently perturbs `{R0, CAPACITY, HA, CURRENT_BIAS}`. Add
   `ParamKind.R1` (and `C1`) with central-difference `∂V/∂R1`, `∂V/∂C1`, so the FIM and the
   estimator can see the dynamics.
2. **Estimator.** Extend the paired fit (`calibration/positive_control.py`, `calibration/external.py`)
   to solve over `{capacity, R0, R1, C1}`. Leave the lack-of-fit screen and the FIM/CRLB
   identifiability gate unchanged in spirit — they now simply see a richer parameter set.
3. **Loop.** Add a `fit-dynamics` mode to `examples/08_real_cell.py` alongside first/second order, and
   print the comparison table.
4. **Tests.** Pin the 4-parameter estimator: self-consistency on matched data, and sane
   identifiability diagnostics.

## Pre-registered hypotheses (stated BEFORE the run)

- **H1 — de-confounding (the hoped-for "less-wrong" win).** Fitting `R1,C1` absorbs the dynamic
  misfit that currently pollutes the capacity fit, so the capacity estimate slides from its phantom
  **+10%** toward the true **−24%**, and/or the lack-of-fit drops materially. The first real-cell
  estimate that is directionally sane.
- **H2 — confounding (the honest bet).** `R1,C1` are poorly identifiable from a 1C-discharge paired
  differential (low excitation), so VIF/CRLB inflate and the verdict shifts
  `REFUSE_MODEL_BIAS → REFUSE_CONFOUNDED` / `WEAK_EVIDENCE`. The refusal persists, but its *reason*
  changes: model rigidity → information poverty.
- **H0 — null.** Little changes, because the dominant residual is the moving OCV (which fitting
  `R1,C1` does not touch); it stays `REFUSE_MODEL_BIAS` with a modest lack-of-fit reduction.

**Prior:** we *expect* H2, or an H0/H2 mix — v0.8's own docs already lean this way. Whichever occurs
is reported as measured. If H1 was the private hope and H2 wins, say so and retract.

## Measured outputs (what v0.9 must print)

- **Per cell × OCV mode:** capacity estimate and lack-of-fit for `{2-param (current), 4-param (v0.9)}`;
  verdict before → after; identifiability diagnostics for the fitted set — VIF of `{R0,R1,C1,Q}`,
  CRLB σ on capacity.
- **Aggregate:** number of verdicts changed and the direction; distribution of capacity-estimate
  movement (did `|estimate − truth|` actually shrink?); the identifiability *cost* of 2→4 params
  (VIF/CRLB inflation).
- **One comparison table** across configs: `1st-2param → 1st-4param → (optional) 2nd-6param`.

## Pass / fail gates

**Pass ≠ "the numbers improved." Pass = "measured honestly, gates green, the claim matches the run."**

1. **The positive control is non-negotiable — this is the v0.4 lesson.** On ECM-generated data with
   *rich* excitation (a pulse train that actually excites the RC dynamics), the 4-parameter estimator
   **must** recover injected `R1,C1` within curvature. A refusal on real data is uninterpretable
   unless the same machinery provably *succeeds* when the dynamics are identifiable. **Build this
   control first**, before looking at a single real cell.
2. **All existing gates stay green:** ruff, ruff format, mypy, pytest (currently **246** total /
   base **229 + 17 deselected** / pybamm **14**), examples 01–08 exit 0, notebooks in sync + executed.
3. **New tests** pin the 4-parameter estimator (matched-data self-consistency; identifiability
   diagnostics behave as claimed).
4. **Docs carry the measured result** with any falsified pre-registration retracted explicitly:
   `REAL_CELL`, `LIMITATIONS` (next section, e.g. §16f), `CLAIMS` (next claim, e.g. C21),
   `REPRODUCIBILITY` counts + pinned table, `README` / `TECHNICAL_REPORT` / `PORTFOLIO`.

## Optional extension — high payoff, foreshadows v1.0

## Measured adjudication (post-run — stamped after the pre-registration above)

Regenerated by `$PY examples/08_real_cell.py` (8-cell Oxford loop) and the positive control
`$PY -m pytest tests/test_dynamics_fit.py`. Canonical numbers live in `REAL_CELL §Fit-dynamics`,
`CLAIMS C21`, `LIMITATIONS §16f`, and the `REPRODUCIBILITY` pinned table — if this note ever disagrees
with those runs, those runs win.

**Verdict: H1 falsified and retracted. Outcome is H0-dominant, with H2 confirmed only on `R1`.**

- **H1 (de-confounding) — FALSIFIED.** Fitting `R1,C1` did **not** slide capacity toward the truth.
  Across 208 scored ages the capacity verdict changed **1/208** — and that one change is
  `REFUSE_MODEL_BIAS → REFUSE_UNOBSERVABLE` (Cell5, cyc2300, estimate `+0.64% → +0.03%`, below the
  noise floor), **not** a diagnosis. Zero ages became `DIAGNOSE`/`WEAK`. Cell1's phantom barely moved,
  `+10.50% → +9.52%`; the largest capacity move anywhere was **3.57%**; the lack-of-fit ratio
  (4-param / 2-param) had median **0.960** — the misfit is essentially untouched. The pre-registered
  hope is retracted.
- **H0 (null) — DOMINANT.** As predicted, the dominant residual is the **moving OCV**, which fitting
  the fast RC branch does not touch: the estimate barely moves and the verdict stays
  `REFUSE_MODEL_BIAS` on 207/208 ages.
- **H2 (confounding) — CONFIRMED, but quarantined to `R1`.** `R1` is indeed unidentifiable from a 1C
  discharge — **VIF(R1) median ≈ 287 ≫ 10** (VIF(C1) ≈ 4.83) — exactly the information-poverty H2
  described. But the confounding stays **inside `R1`**: capacity's own VIF stays ~4 and its CRLB σ
  inflates only ×**1.025**, so the capacity refusal never flips to `REFUSE_CONFOUNDED`. H2's mechanism
  is real; its predicted effect on the *capacity* verdict is not.

**The positive control passed first (the v0.4 lesson).** On ECM data with a pulse train, the 4-param
gauss-newton recovers injected `R1 0.15 → 0.1500` and `C1 0.30 → 0.3000` with zero cross-talk; the same
`R1` fault is `DIAGNOSE`d under pulses yet `REFUSE_CONFOUNDED` under constant current. So the real-cell
refusal is interpretable: the limit is the **excitation**, not the code.

**Net:** v0.9 sharpens v0.8 rather than overturning it. A *fixed* second branch was invisible (0/208);
a *fitted* fast branch is inert too (1/208), because a 1C discharge cannot identify it and the phantom
is OCV drift regardless. This is the forward-pointing null the Optional extension anticipated: the
honest next step is richer excitation (a designed pulse test) and an observer that can express OCV
drift — carried into the v1.0 arc.

**The Optional extension is implemented** (`examples/03` act 6, `vif_under_excitation`): reusing the
next-best-test machinery, it ranks candidate excitations by VIF and prints the pulse train that drops
`VIF(R1)` below 10 — the cheapest test that *earns the dynamics* — alongside the measured proof that
the same test leaves the capacity verdict untouched (capacity's VIF barely moves across every
excitation; its refusal is model bias, not confounding). One correction to the extension's framing as
written above: it converts the refusal into "here is the cheapest test to earn **the dynamics**," not
"the diagnosis" — because the capacity phantom is OCV drift, and no excitation reaches it. The
prescription is regenerated, not asserted, and `tests/test_dynamics_fit.py` pins both halves.
